## 新闻聚合

全面的 AI 驱动新闻聚合和分析工具。

- **[ai-news-radar](https://github.com/LearnPrompt/ai-news-radar)** ⭐⭐⭐⭐⭐ - 实时 AI 资讯追踪，支持 10+ 网页源、OPML RSS、24h 双视图（AI 强相关/全量）、失败源自动处理。*最活跃*
- **[clawfeed](https://github.com/kevinho/clawfeed)** ⭐⭐⭐⭐⭐ - 多频率摘要系统（4小时/日/周/月），支持 AI 深度分析、书签功能、Google OAuth 多用户。*功能最完整*
- **[TrendRadar](https://github.com/sansan0/TrendRadar)** ⭐⭐⭐⭐⭐ - 企业级信息推送，支持 MCP AI 分析、10+ 推送渠道（企业微信、Telegram、钉钉、飞书、邮件等）、统一时间线调度。*企业就绪*
- **[DAK News](https://github.com/LittleLittleCloud/The-Grand-Archive)** ⭐⭐⭐⭐ - 专为AI设计的新闻档案库，覆盖30+信源，每30分钟更新，支持全文搜索、REST API、SDK 和 CLI。*生产级 API*
- **[auto-news](https://github.com/finaldie/auto-news)** ⭐⭐⭐⭐ - 基于 LLM 的自动新闻聚合器，快速了解趋势。
- **[hot_news_daily_push](https://github.com/tuber0613/hot_news_daily_push)** ⭐⭐⭐⭐ - 多平台热点新闻收集，支持 RSS、Twitter Feed、去重总结、多渠道推送。
- **[meridian](https://github.com/iliane5/meridian)** ⭐⭐⭐⭐ - 抓取数百个信息源，AI 分析，提供个性化日报。
- **[ai-daily-digest](https://github.com/vigorX777/ai-daily-digest)** ⭐⭐⭐ - TypeScript + Bun 驱动的五步流水线 AI 日报。
- **[ai-daily-skill](https://github.com/geekjourneyx/ai-daily-skill)** ⭐⭐⭐ - 每日 AI 技能报告和学习资源。
- **[CloudFlare-AI-Insight-Daily](https://github.com/justlovemaki/CloudFlare-AI-Insight-Daily)** ⭐⭐⭐ - Cloudflare Workers + Gemini 驱动的 AI 日报，支持 GitHub Pages 部署。

## RSS 管理与增强

RSS 订阅源处理、过滤和 AI 增强工具。

- **[FeedCraft](https://github.com/Colin-XKL/FeedCraft)** ⭐⭐⭐⭐⭐ - 高性能 Go 语言 RSS 生成器（HTML/Curl/Search 转 RSS），支持 AI 集成和自定义 prompt。*最佳架构*
- **[RSS-Master](https://github.com/TD21forever/RSS-Master)** ⭐⭐⭐⭐ - 自定义过滤、AI 总结、打分、异步处理 RSS 订阅源。
- **[RSSBox](https://github.com/versun/RSSBox)** ⭐⭐⭐⭐ - 智能 RSS 管理，高效信息获取（原 RSS Translator）。
- **[FreshRSS](https://github.com/FreshRSS/FreshRSS)** ⭐⭐⭐⭐⭐ - 成熟的多用户 RSS 聚合器，支持 20+ 语言、插件系统、WebSub。*生产就绪*
- **[FeedMe](https://github.com/Seanium/FeedMe)** ⭐⭐⭐⭐ - 轻量级 React RSS 阅读器，支持 AI 摘要和零成本部署。
- **[AI-RSS](https://github.com/wolfitem/AI-RSS)** ⭐⭐⭐ - AI 增强的 RSS 阅读体验。
- **[huntly](https://github.com/lcomplete/huntly)** ⭐⭐⭐ - 信息管理和知识组织工具。

## 播客生成

将 RSS 订阅源和新闻转换为 AI 生成的播客。

- **[PodRSS](https://github.com/LetTTGACO/PodRSS)** ⭐⭐⭐⭐ - Next.js + Cloudflare Workers 驱动的 RSS 转播客，支持 AI 摘要和 Edge TTS 语音合成。
- **[rss_ai_podcast](https://github.com/astralwaveio/rss_ai_podcast)** ⭐⭐⭐⭐ - 多源 RSS + Gemini 摘要 + Azure TTS + Telegram/微信推送。
- **[rss2podcast](https://github.com/intothevoid/rss2podcast)** ⭐⭐⭐ - 本地部署的 AI 生成播客。
- **[newpodcastforAI](https://github.com/zacfire/newpodcastforAI)** ⭐⭐⭐ - 精选 AI 相关播客 RSS 聚合。

## 快速开始

### 零配置
1. **[ai-news-radar](https://github.com/LearnPrompt/ai-news-radar)** - Fork → GitHub Actions 自动运行
